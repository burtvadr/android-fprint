# Icon assets

The fingerprint mark used by this project is a heavily modified derivative of
the **Fingerprint** icon from the **Security 15** collection on SVG Repo:

- Source: <https://www.svgrepo.com/svg/246819/fingerprint>
- Collection: <https://www.svgrepo.com/collection/security-15/>
- License: [CC0](https://www.svgrepo.com/page/licensing/#CC0)
- Uploader: SVG Repo; no individual artist is listed.

The dark/light, Material 3, and scrcpy variants, the Android adaptive-icon
foregrounds, and the in-app glyph are derivative works of that mark. The
repository's 0BSD license applies to the application code; the source icon is
CC0.
